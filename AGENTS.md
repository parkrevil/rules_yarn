# Project
rules_yarn is a set of Bazel rules for integrating Yarn.

# Rules
- Review all rules in official Bazel repositories and follow applicable implementation patterns and configuration methods from those repositories and the official Bazel documentation.
- Use https://github.com/bazel-contrib/rules-template as a structural reference, checking its patterns and configuration against the official documentation for the selected Bazel version.
- Verify and use the latest stable versions of Bazel and rule dependencies. Follow the official documentation for those versions.
- Keep implementations simple and correct, without workarounds or unnecessary complexity.
